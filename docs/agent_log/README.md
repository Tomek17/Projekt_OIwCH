# Agent log

Evidence for the report. Written by the agent while working, reviewed by the student.
Times are UTC. Entries are append-only; corrections are added as new entries, not edits.

- `decisions.md`: non-trivial decisions (reasoning, alternatives)
- `interventions.md`: human corrected / redirected / unblocked the agent
- `failures.md`: agent mistakes and near-misses, how detected, fix
- `metrics.md`: counts and timings per phase
- `runs.log`: one line per solver run, appended automatically by a hook (created on first run)
